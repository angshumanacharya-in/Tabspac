Maximum Product of Two Digits (LeetCode 3536)

Introduction

The Maximum Product of Two Digits problem is a simple digit manipulation problem that tests your ability to extract digits from an integer and process them efficiently.

Instead of generating every possible pair of digits, we can solve the problem in a single traversal by keeping track of the two largest digits. This leads to an elegant O(d) solution, where d is the number of digits in the given integer.

Problem Statement

You are given a positive integer n.

Your task is to return the maximum product of any two digits present in the number.

Note: The same digit can be used twice only if it appears at least twice in the number.

Example 1

Input: n = 31
Digits: [3, 1]
Possible products: 3 × 1 = 3
Output: 3

Example 2

Input: n = 22
Digits: [2, 2]
Possible products: 2 × 2 = 4
Output: 4

Example 3

Input: n = 124
Digits: [1, 2, 4]
Possible products: 1 × 2 = 2, 1 × 4 = 4, 2 × 4 = 8
Output: 8

Constraints

10 ≤ n ≤ 10^9

Since the largest possible number has only 10 digits, even straightforward approaches are fast enough.

Optimal Approach (Single Pass)

Instead of comparing every pair, we can keep track of two variables during a single traversal:

  • largest: Stores the maximum digit found so far.
  • secondLargest: Stores the second-largest digit found so far.

As we extract each digit using modulo arithmetic (n % 10), we compare it against our current top two. If a digit is greater than or equal to largest, we shift the old largest down to secondLargest and update largest. Otherwise, if it is strictly greater than secondLargest, we update secondLargest. After processing all digits, the answer is simply largest × secondLargest.

Code Implementations

class Solution {
public:
    int maxProduct(int n) {
        int largest = 0, secondLargest = 0;

        while (n > 0) {
            int digit = n % 10;

            if (digit >= largest) {
                secondLargest = largest;
                largest = digit;
            } else if (digit > secondLargest) {
                secondLargest = digit;
            }

            n /= 10;
        }

        return largest * secondLargest;
    }
};
class Solution:
    def maxProduct(self, n: int) -> int:
        largest = 0
        second_largest = 0

        while n > 0:
            digit = n % 10

            if digit >= largest:
                second_largest = largest
                largest = digit
            elif digit > second_largest:
                second_largest = digit

            n //= 10

        return largest * second_largest

Alternative Approach (Sorting)

An alternative, straightforward way to solve this problem is to extract every digit from the number, store them inside a dynamic array or list, and then sort the collection in ascending order. Once sorted, the two largest digits will naturally reside at the very end of the array. Multiplying the last two elements gives us the correct answer immediately.

Code Implementations

class Solution {
public:
    int maxProduct(int n) {
        vector<int> digits;

        while (n > 0) {
            digits.push_back(n % 10);
            n /= 10;
        }

        sort(digits.begin(), digits.end());

        int m = digits.size();
        return digits[m - 1] * digits[m - 2];
    }
};
class Solution:
    def maxProduct(self, n: int) -> int:
        digits = []

        while n > 0:
            digits.append(n % 10)
            n //= 10

        digits.sort()

        return digits[-1] * digits[-2]

Complexity Analysis

Approach Time Complexity Space Complexity
Optimal Approach O(d) O(1)
Sorting Approach O(d log d) O(d)

Key Takeaways

  • The maximum product always comes from the two largest digits.
  • Tracking the two largest digits is more efficient than checking every pair.
  • The optimal solution runs in O(d) time and O(1) extra space.
  • This problem is an excellent introduction to digit extraction and one-pass optimization techniques.
