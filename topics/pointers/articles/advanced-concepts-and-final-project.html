2. Void Pointers (void *) & Pointer Casting

A void pointer is a generic pointer that can hold the address of any data type. Unlike typed pointers, a void * has no associated data type, meaning it cannot be dereferenced directly without casting it to the appropriate pointer type first.

#include <stdio.h>

int main()
{
    int num = 100;
    float value = 45.5f;
    void *ptr;

    ptr = &num;
    printf("%d\n", *(int *)ptr);

    ptr = &value;
    printf("%.2f\n", *(float *)ptr);

    return 0;
}

3. Pointer Qualifiers: const, volatile, & restrict

Qualifiers add control over how variables and pointers interact during compiler optimizations and runtime:

  • Pointer to Constant (const int *ptr): The pointer can point to different locations, but data cannot be modified through it.
  • Constant Pointer (int *const ptr): The pointer address is fixed, but the underlying data can be modified.
  • Volatile Pointer: Tells the compiler that a variable's value may change unexpectedly (crucial for hardware registers or multithreading).
  • Restrict Pointer (C99): Guarantees that a pointer is the sole reference to the memory block, enabling aggressive compiler optimizations.

4. Memory Alignment, Structure Padding & Null Pointers

Processors access aligned memory more efficiently. Compilers insert invisible padding bytes inside structures to ensure members align with architecture word boundaries (which can be observed using sizeof()).

Additionally, always initialize unassigned pointers to NULL and validate them before dereferencing to prevent undefined behavior.

5. Hands-On Exercise: Generic Swap Using `void *`

#include <stdio.h>
#include <string.h>

void swap(void *a, void *b, size_t size)
{
    char temp[size];
    memcpy(temp, a, size);
    memcpy(a, b, size);
    memcpy(b, temp, size);
}

int main()
{
    int x = 10;
    int y = 20;

    swap(&x, &y, sizeof(int));
    printf("x = %d\n", x);
    printf("y = %d\n", y);

    return 0;
}

7. Key Concepts Reference

Concept / Qualifier Description
void *ptr Generic pointer requiring explicit cast before dereferencing
const int *ptr Pointer to constant data (data is read-only)
int *const ptr Constant pointer (address destination is locked)
restrict Keyword promising exclusive access to target memory block
Structure Padding Compiler byte insertion to optimize CPU memory alignment access
