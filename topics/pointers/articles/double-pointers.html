1. Introduction

As your C programs become more advanced, you'll often encounter situations where a single pointer is not enough. You may need to modify a pointer inside a function, dynamically allocate two-dimensional arrays, or implement complex data structures such as linked lists, trees, and graphs. These tasks require double pointers, also known as pointers to pointers.

A double pointer stores the address of another pointer, adding an extra level of indirection. While this concept may initially seem confusing, understanding the memory layout and practicing with examples makes it much easier. Double pointers are an essential part of professional C programming and are widely used in operating systems, compilers, memory management libraries, and large-scale software.

2. What is a Double Pointer?

A double pointer is a pointer that stores the address of another pointer. It is declared using two asterisks: int **ptr;, meaning it stores the address of an int *.

Multiple Levels of Indirection

int num = 100;
int *ptr = #
int **dptr = &ptr;
dptr (Stores address of ptr)
↓ (*dptr)
ptr (Stores address of num)
↓ (*ptr or **dptr)
num (Value: 100)

3. Modifying Pointers Inside Functions

When you pass a normal pointer to a function, a copy of the pointer is created, so changing it inside the function does not affect the original pointer. By passing a double pointer (address of the pointer), the function can modify the original pointer directly.

#include <stdio.h>
#include <stdlib.h>

void allocate(int **ptr)
{
    *ptr = (int *)malloc(sizeof(int));
    if(*ptr != NULL)
    {
        **ptr = 100;
    }
}

int main()
{
    int *num = NULL;
    allocate(&num);
    printf("%d\n", *num); // Outputs 100
    free(num);

    return 0;
}

4. Dynamic Two-Dimensional Arrays Using Double Pointers

Double pointers are frequently used to create dynamic 2D matrices where rows are allocated independently on the heap.

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int rows = 3, cols = 4;
    int **matrix = (int **)malloc(rows * sizeof(int *));

    for(int i = 0; i < rows; i++)
    {
        matrix[i] = (int *)malloc(cols * sizeof(int));
    }

    // Usage and assignment
    matrix[1][2] = 42;
    printf("%d\n", matrix[1][2]);

    // Proper cleanup (freeing rows then matrix)
    for(int i = 0; i < rows; i++)
    {
        free(matrix[i]);
    }
    free(matrix);

    return 0;
}

5. Arrays of Strings

Multiple strings can be efficiently organized and manipulated using an array of character pointers, which behaves as a char **.

#include <stdio.h>

int main()
{
    char *names[] = { "Alice", "Bob", "Charlie" };
    char **ptr = names;

    for(int i = 0; i < 3; i++)
    {
        printf("%s\n", ptr[i]);
    }

    return 0;
}

6. Common Beginner Mistakes

  • Forgetting Levels of Dereferencing: Trying to access a value with *dptr instead of the correct double dereference **dptr.
  • Not Allocating Rows for Matrices: Attempting to use matrix[i][j] before allocating memory for individual rows.
  • Improper Deallocation Order: Freeing the base pointer array before freeing each individual row pointer, causing memory leaks or segmentation faults.
  • Confusing Declarations: Mixing up int **ptr (pointer to pointer) with int (*ptr)[5] (pointer to an array of 5 integers).

7. Mini Project: Matrix Multiplication Using Dynamic Memory

Write a C program that dynamically allocates two matrices using double pointers, multiplies them, displays the result, and releases all allocated memory.

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int rows1 = 2, cols1 = 2;
    int rows2 = 2, cols2 = 2;

    int **A = (int **)malloc(rows1 * sizeof(int *));
    int **B = (int **)malloc(rows2 * sizeof(int *));
    int **C = (int **)malloc(rows1 * sizeof(int *));

    for(int i = 0; i < rows1; i++)
    {
        A[i] = (int *)malloc(cols1 * sizeof(int));
        C[i] = (int *)malloc(cols2 * sizeof(int));
    }

    for(int i = 0; i < rows2; i++)
    {
        B[i] = (int *)malloc(cols2 * sizeof(int));
    }

    int valuesA[2][2] = {{1, 2}, {3, 4}};
    int valuesB[2][2] = {{5, 6}, {7, 8}};

    for(int i = 0; i < rows1; i++)
    {
        for(int j = 0; j < cols1; j++)
        {
            A[i][j] = valuesA[i][j];
            B[i][j] = valuesB[i][j];
        }
    }

    for(int i = 0; i < rows1; i++)
    {
        for(int j = 0; j < cols2; j++)
        {
            C[i][j] = 0;
            for(int k = 0; k < cols1; k++)
            {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }

    printf("Result Matrix:\n");
    for(int i = 0; i < rows1; i++)
    {
        for(int j = 0; j < cols2; j++)
        {
            printf("%d ", C[i][j]);
        }
        printf("\n");
    }

    for(int i = 0; i < rows1; i++)
    {
        free(A[i]);
        free(C[i]);
    }
    for(int i = 0; i < rows2; i++)
    {
        free(B[i]);
    }

    free(A);
    free(B);
    free(C);

    return 0;
}

8. Key Concepts Reference

Syntax / Concept Description

**dptr Double dereferencing to access the underlying value
allocate(&ptr) Passing pointer address to modify the pointer inside a function

Summary

Double pointers add an extra level of indirection by storing the address of another pointer. They are essential for modifying pointers inside functions, creating dynamic two-dimensional arrays, managing arrays of strings, and implementing advanced data structures. In this lesson, you learned how double pointers work, how to access values using multiple levels of dereferencing, how to allocate and free dynamic matrices, and how to build a matrix multiplication program using dynamic memory.
