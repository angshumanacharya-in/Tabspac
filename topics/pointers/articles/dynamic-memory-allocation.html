Dynamic Memory Allocation in C

Learning Objectives

  • Understand dynamic memory allocation.
  • Differentiate between stack and heap memory.
  • Allocate memory using malloc().
  • Allocate initialized memory using calloc().
  • Resize allocated memory using realloc().
  • Release memory using free().
  • Understand memory leaks and dangling pointers.
  • Use pointers to pointers (int **).
  • Create and resize dynamic arrays.

1. Introduction & Why Dynamic Memory Allocation?

One of the biggest strengths of the C programming language is its ability to allocate memory dynamically during program execution. Unlike static memory allocation, where the memory size is fixed at compile time, dynamic memory allocation allows programs to request, resize, and release memory as needed. This flexibility is essential for building scalable applications such as databases, text editors, operating systems, compilers, and data structures like linked lists, stacks, queues, and trees.

Using a fixed array like int marks[100]; has severe drawbacks: if there are only 10 students, memory is wasted; if there are 500, it is insufficient. Dynamic allocation solves this by requesting exact sizes at runtime.

2. Memory Organization: Stack vs. Heap

A typical C program organizes memory into distinct regions, most notably the Stack and the Heap.

Stack Memory Heap Memory
Stores local variables and function parameters Stores dynamically allocated memory (malloc, calloc)
Automatically managed by the compiler Explicitly managed by the programmer
Fast allocation and deallocation Slightly slower allocation
Destroyed when function scope ends Persists until explicitly freed or program exits

3. Allocation Functions: malloc() and calloc()

The standard library <stdlib.h> provides core memory management functions:

malloc()

Allocates a block of memory of requested bytes, leaving contents uninitialized (containing garbage values).

int *ptr = (int *)malloc(sizeof(int));
if(ptr == NULL) {
    // Handle allocation failure
}

calloc()

Allocates memory for multiple elements and automatically initializes all allocated bytes to zero.

int *arr = (int *)calloc(5, sizeof(int)); // Allocates 5 ints, all set to 0

4. Resizing and Releasing Memory: realloc() and free()

realloc()

Changes the size of an existing memory block. If contiguous space isn't available, it relocates the block entirely and copies existing data.

arr = (int *)realloc(arr, 10 * sizeof(int));

free()

Releases dynamically allocated memory back to the system so it can be reused.

free(ptr);
ptr = NULL; // Best practice to prevent dangling pointers

5. Common Pitfalls: Memory Leaks & Dangling Pointers

  • Memory Leaks: Occur when dynamically allocated memory is abandoned without calling free(), exhausting system RAM over time.
  • Dangling Pointers: Pointers that continue referencing memory locations after they have been freed. Setting pointers to NULL immediately after freeing avoids this.
  • Forgetting NULL Checks: Always verify that allocation functions did not return NULL before attempting to dereference pointers.

6. Pointers to Pointers (int **)

A double pointer stores the memory address of another pointer variable. They are essential for creating dynamic 2D arrays, multi-level structures, or allowing functions to modify the address stored inside an external pointer.

void allocate(int **ptr) {
    *ptr = (int *)malloc(sizeof(int));
}

7. Mini Project: Dynamic Integer Array with Resizing

A complete program demonstrating dynamic allocation, user input, resizing with realloc(), and proper cleanup.

#include <stdio.h>
#include <stdlib.h>

int main()
{
    int n, extra;

    printf("Enter initial size: ");
    scanf("%d", &n);

    int *arr = (int *)malloc(n * sizeof(int));
    if(arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    printf("Enter %d elements:\n", n);
    for(int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
    }

    printf("Enter additional size: ");
    scanf("%d", &extra);

    arr = (int *)realloc(arr, (n + extra) * sizeof(int));
    if(arr == NULL) {
        printf("Memory reallocation failed\n");
        return 1;
    }

    printf("Enter %d additional elements:\n", extra);
    for(int i = n; i < n + extra; i++) {
        scanf("%d", &arr[i]);
    }

    printf("Complete Array:\n");
    for(int i = 0; i < n + extra; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);
    return 0;
}

8. Key Concepts Reference

Function / Concept Description
malloc(size) Allocates uninitialized memory block of given bytes
calloc(num, size) Allocates and zero-initializes memory for an array of elements
realloc(ptr, new_size) Resizes previously allocated memory block
free(ptr) Releases heap memory block back to the system
int **dptr Pointer to pointer; used for modifying pointers or 2D allocations

Summary

Dynamic memory allocation enables C programs to request and manage memory at runtime, making them flexible and efficient for handling data whose size is unknown until execution. In this lesson, you learned the differences between stack and heap memory, how to allocate memory using malloc() and calloc(), resize memory with realloc(), release memory with free(), and avoid common issues such as memory leaks and dangling pointers. You also explored pointers to pointers and built a dynamic array that can grow during program execution.
