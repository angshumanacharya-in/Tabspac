1. Introduction

Pointers are one of the most powerful and unique features of the C programming language. They provide direct access to memory, making programs more efficient, flexible, and capable of performing advanced tasks such as dynamic memory allocation, data structure implementation, and low-level system programming. Although pointers are often considered difficult for beginners, understanding the fundamentals makes them much easier to work with.

In this lesson, we'll explore what pointers are, how they work, how to declare and initialize them, and how to use the address-of (&) and dereference (*) operators. By the end of this chapter, you'll be able to access variables through pointers and understand why pointers are essential in C.

2. What is a Pointer?

A pointer is a variable that stores the memory address of another variable. Unlike normal variables that store actual values, pointers store locations in memory where those values are kept.

For example, suppose variable x = 25 is stored at memory location 1000. If int *ptr; stores the address of x, then:

ptr (Stores Address 1000)
↓
x (Value: 25 at Address 1000)

The pointer doesn't store 25. It stores the address where 25 exists.

3. Why Do We Need Pointers?

Pointers provide several important advantages:

  • 1. Efficient Memory Usage: Instead of copying large amounts of data, programs can simply pass memory addresses. This saves both time and memory.
  • 2. Dynamic Memory Allocation: Pointers allow memory to be allocated during program execution using functions like malloc(), calloc(), and realloc(). Without pointers, dynamic memory management is impossible.
  • 3. Function Communication: Pointers allow functions to modify original variables instead of copies (e.g., swapping values using swap(&a, &b)).
  • 4. Data Structures: Pointers are the foundation of linked lists, trees, graphs, queues, stacks, and hash tables.
  • 5. System Programming: Operating systems, device drivers, and embedded systems rely heavily on pointers for efficient memory access.

4. Pointer Declaration & Initialization

General syntax for declaring a pointer:

datatype *pointerName;

Examples: int *ptr;, char *ch;, float *fptr;, double *dptr;. The * indicates that the variable is a pointer.

Pointer Initialization

A pointer should always point to a valid memory location.

int num = 50;
int *ptr = &num;

Here, ptr stores the address of num, meaning ptr == &num (both contain the same memory address).

Complete Example

#include <stdio.h>

int main()
{
    int num = 50;
    int *ptr = &num;

    printf("Value of num = %d\n", num);
    printf("Address of num = %p\n", (void *)&num);
    printf("Pointer value = %p\n", (void *)ptr);

    return 0;
}

5. Pointer Types & Size

Pointers are typed because different data types occupy different amounts of memory.

  • Integer Pointer: int x = 5; int *ptr = &x;
  • Character Pointer: char ch = 'A'; char *ptr = &ch;
  • Float Pointer: float price = 99.5; float *ptr = &price;
  • Double Pointer: double pi = 3.14159; double *ptr = &pi;

Pointer Size

Regardless of the data type, pointer size depends on the system architecture (32-bit systems use 4 bytes; 64-bit systems use 8 bytes).

#include <stdio.h>

int main()
{
    int *p;
    char *c;
    float *f;

    printf("%zu\n", sizeof(p));
    printf("%zu\n", sizeof(c));
    printf("%zu\n", sizeof(f));

    return 0;
}

6. The Address-of (&) and Dereference (*) Operators

  • Address-of (&) Operator: Returns the memory address of a variable (e.g., &num). Think of it as finding an address.
  • Dereference (*) Operator: Accesses the value stored at the memory location held by a pointer (e.g., *ptr). Think of it as going to that address.

Modifying Variables Through Pointers

Pointers can change the original variable directly:

#include <stdio.h>

int main()
{
    int num = 10;
    int *ptr = &num;

    *ptr = 100;
    printf("%d", num);

    return 0;
}

7. Common Beginner Mistakes

  • Using Uninitialized Pointers: Attempting to assign values to uninitialized pointers (e.g., int *ptr; *ptr = 5;) causes undefined behavior.
  • Forgetting the &: Assigning a variable directly to a pointer instead of its address (int *ptr = x; instead of int *ptr = &x;).
  • Confusing * and &: Mixing up the address operator and the dereference operator.
  • Printing Addresses Incorrectly: Always use %p and cast to (void *)&x for standard compliance.

8. Assignment: Swap Two Numbers Using Pointers

Write a C program that swaps two integer variables using pointers.

#include <stdio.h>

void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main()
{
    int x = 10;
    int y = 20;

    printf("Before Swap:\nx = %d\ny = %d\n", x, y);

    swap(&x, &y);

    printf("\nAfter Swap:\nx = %d\ny = %d\n", x, y);

    return 0;
}

9. Key Concepts Reference

Expression / Syntax Meaning / Purpose

ptr = &num; Initialize pointer with the address of num
&num Address-of operator (gets memory location)
*ptr Dereference operator (gets or sets value at address)
%p Format specifier for printing memory addresses safely

Summary

Pointers are variables that store memory addresses, enabling direct access to data in memory. They form the foundation of many advanced concepts in C, including dynamic memory allocation, efficient function parameter passing, and complex data structures like linked lists and trees.
