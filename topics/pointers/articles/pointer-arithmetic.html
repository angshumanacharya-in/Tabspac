1. Introduction

Pointers become truly powerful when combined with pointer arithmetic. Unlike ordinary variables, pointers can be incremented, decremented, compared, and subtracted to navigate through memory efficiently. Pointer arithmetic is widely used for array traversal, string manipulation, dynamic memory management, and implementing complex data structures.

In this lesson, you'll learn how pointer arithmetic works, why pointer increments depend on data types, how arrays and pointers interact, and how to safely perform arithmetic operations on pointers.

2. What is Pointer Arithmetic?

Pointer arithmetic means performing mathematical operations on pointers to move between memory locations. Unlike ordinary integers, adding 1 to a pointer does not increase its address by 1 byte. Instead, it moves to the next object of the pointer's data type.

For example, given int arr[5]; int *ptr = arr; where an integer occupies 4 bytes:

ptr = 1000 (Value: 10)
↓ (after ptr++)
ptr = 1004 (Value: 20)

It moved to the next integer automatically based on the data type size.

3. Why Does Pointer Arithmetic Work This Way?

Every data type occupies a certain number of bytes. When a pointer moves, the new address equals the current address plus the size of the data type.

Data Type Typical Size
char 1 byte
short 2 bytes
int 4 bytes
float 4 bytes
double 8 bytes

Therefore, a char *ptr moves by 1 byte, whereas a double *ptr moves by 8 bytes on most systems.

4. Basic Operations: Increment, Decrement, Addition & Subtraction

  • Incrementing (++): Moves the pointer to the next memory location of its data type.
  • Decrementing (--): Moves a pointer to the previous memory location.
  • Addition: You can add an integer to a pointer (e.g., ptr = ptr + 3;) to jump forward by multiple elements.
  • Subtraction: Subtracting an integer moves backwards through memory (e.g., ptr = ptr - 2;).

Example: Incrementing Pointers

#include <stdio.h>

int main()
{
    int arr[] = {10, 20, 30};
    int *ptr = arr;

    printf("%d\n", *ptr); // Outputs 10
    ptr++;
    printf("%d\n", *ptr); // Outputs 20

    return 0;
}

5. Difference and Comparison Between Pointers

Difference Between Two Pointers

Two pointers pointing to elements of the same array can be subtracted (e.g., p2 - p1). It returns the number of elements between them, not the number of bytes.

Pointer Comparisons

Pointers can be compared using ==, !=, <, >, <=, and >=. Comparisons should generally be used only when both pointers belong to the same array or contiguous memory block.

Invalid Arithmetic

Operations like multiplication (ptr * 2), division (ptr / 3), or modulus (ptr % 2) are strictly invalid on pointers.

6. Pointer Arithmetic vs Array Arithmetic

There is a fundamental equivalence in C between array notation and pointer notation:

arr[i] == *(arr + i)

This relationship allows seamless traversal of arrays using pointers instead of index variables.

Example: Traversing an Array Using Pointers

#include <stdio.h>

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int *ptr = arr;

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", *ptr);
        ptr++;
    }

    return 0;
}

7. Typecasting Pointers & Common Mistakes

Sometimes we convert one pointer type into another (e.g., viewing an integer's bytes via char *ptr = (char *)&x;) to inspect memory differently or work with generic pointers (`void *`).

Common Beginner Mistakes

  • Assuming ptr++ Increases by One Byte: Forgetting that pointer increments scale by the size of the data type (e.g., +4 for `int`).
  • Going Beyond Array Bounds: Pointing past the end of an array (e.g., &arr[5]) and dereferencing it leads to undefined behavior.
  • Comparing Unrelated Pointers: Comparing pointers that do not point to the same array or block of memory.
  • Mixing Pointer Types: Assigning mismatched pointer types without explicit typecasting.

8. Mini Project: Reverse an Array Using Pointers

Write a C program to reverse an integer array in place using only pointer arithmetic.

#include <stdio.h>

void reverse(int *start, int *end)
{
    while(start < end)
    {
        int temp = *start;
        *start = *end;
        *end = temp;

        start++;
        end--;
    }
}

int main()
{
    int arr[] = {1, 2, 3, 4, 5};
    int n = sizeof(arr) / sizeof(arr[0]);

    reverse(arr, arr + n - 1);

    printf("Reversed Array:\n");
    for(int i = 0; i < n; i++)
    {
        printf("%d ", arr[i]);
    }

    return 0;
}
