1. Introduction

Pointers and arrays are among the most closely related concepts in C. In fact, much of the power of pointers comes from their relationship with arrays. Understanding this connection enables you to write efficient programs, process large amounts of data, work with multidimensional arrays, and pass arrays to functions without unnecessary copying.

In this lesson, you'll learn how arrays are stored in memory, how array names behave like pointers, how to access array elements using pointers, how arrays are passed to functions, and how to work with multidimensional arrays using pointers.

2. Arrays and Memory & The Array Name

An array stores elements in contiguous memory locations. The name of an array represents the address of its first element (i.e., arr == &arr[0]).

#include <stdio.h>

int main()
{
    int arr[5] = {10, 20, 30, 40, 50};

    printf("%p\n", (void *)arr);
    printf("%p\n", (void *)&arr[0]);

    return 0;
}

Array Name vs Pointer Variable

Although an array name behaves like a pointer, it is a constant pointer to the first element. You can do int *ptr = arr; and increment ptr++, but doing arr++ is invalid because the array base address cannot be changed.

3. Accessing and Modifying Array Elements Using Pointers

Array indexing and pointer notation are directly interchangeable using the rule arr[i] == *(arr + i):

Array Notation Pointer Notation
arr[0] *(arr)
arr[1] *(arr + 1)
arr[2] *(arr + 2)
arr[i] *(arr + i)

As a quirky C fact, 2[arr] is also valid because addition is commutative, though it should never be used in production code!

Example: Traversing and Modifying

#include <stdio.h>

int main()
{
    int arr[] = {10, 20, 30, 40, 50};
    int *ptr = arr;

    while(ptr < arr + 5)
    {
        printf("%d ", *ptr);
        ptr++;
    }

    return 0;
}

4. Passing Arrays to Functions

Arrays are passed to functions as pointers, meaning only the base memory address is passed instead of copying the entire array. This saves massive amounts of memory and CPU cycles.

#include <stdio.h>

void doubleElements(int *arr, int n)
{
    for(int i = 0; i < n; i++)
        arr[i] *= 2;
}

int main()
{
    int arr[] = {1, 2, 3, 4};
    doubleElements(arr, 4);

    for(int i = 0; i < 4; i++)
        printf("%d ", arr[i]); // Outputs: 2 4 6 8

    return 0;
}

5. Multidimensional Arrays & Pointers

Multidimensional arrays like 2D matrices are also stored sequentially in contiguous memory. To point to an entire row of a 2D array, we use a pointer to an array:

int (*ptr)[3]; // Pointer to an array of 3 integers
// Note: int *ptr[3] is an array of 3 integer pointers (different!)

Accessing 2D Elements Using Pointers

To access an element like matrix[i][j] using pointer notation, we use:

*(*(matrix + i) + j)

Example: Traversing a Matrix

#include <stdio.h>

int main()
{
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for(int i = 0; i < 2; i++)
    {
        for(int j = 0; j < 3; j++)
        {
            printf("%d ", *(*(matrix + i) + j));
        }
        printf("\n");
    }

    return 0;
}

6. Common Beginner Mistakes

  • Modifying Array Names: Trying to write expressions like arr++. Array names are constant base pointers.
  • Operator Precedence Errors: Writing *arr + 2 instead of parenthesizing it properly as *(arr + 2).
  • Incorrect Matrix Pointers: Declaring int *ptr = matrix; instead of the correct row-pointer syntax int (*ptr)[3] = matrix;.
  • Assuming Array Copying: Forgetting that arrays passed to functions decay into pointers and modify the original dataset.

7. Assignment: Matrix Addition Using Pointer Notation

Write a C program that adds two matrices using only pointer notation.

#include <stdio.h>

int main()
{
    int a[2][2] = {{1, 2}, {3, 4}};
    int b[2][2] = {{5, 6}, {7, 8}};
    int result[2][2];

    for(int i = 0; i < 2; i++)
    {
        for(int j = 0; j < 2; j++)
        {
            *(*(result + i) + j) = *(*(a + i) + j) + *(*(b + i) + j);
        }
    }

    printf("Result Matrix:\n");
    for(int i = 0; i < 2; i++)
    {
        for(int j = 0; j < 2; j++)
        {
            printf("%d ", result[i][j]);
        }
        printf("\n");
    }

    return 0;
}

8. Key Concepts Reference

Expression / Concept Description
arr vs &arr[0] Both represent the constant memory address of the first array element
*(arr + i) Equivalent pointer notation for array subscript indexing arr[i]
int *arr (in function) Function parameter syntax receiving a decayed array reference
int (*ptr)[3] Pointer to a 1D array of 3 integers (used for 2D matrices)
*(*(matrix + i) + j) Pointer access for 2D matrix element matrix[i][j]

Summary

Pointers and arrays are tightly connected in C. An array name represents the address of its first element, allowing arrays to be accessed and traversed using pointer arithmetic. In this lesson, you learned how to access and modify array elements with pointers, pass arrays to functions efficiently, understand why arrays decay to pointers in function calls, and work with multidimensional arrays using pointer notation.
