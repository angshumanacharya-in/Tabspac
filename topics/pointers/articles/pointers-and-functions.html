1. Introduction

Functions and pointers are a powerful combination in C. While functions help organize code into reusable blocks, pointers allow those functions to directly access and modify data stored in memory. Together, they enable efficient programming, avoid unnecessary data copying, and form the foundation for advanced concepts such as callbacks, dynamic memory management, and data structures.

In this lesson, you'll learn the difference between pass-by-value and pass-by-reference, how to use pointers as function parameters, how to safely return pointers from functions, the concepts of const pointers and pointers to const, and get an introduction to function pointers.

2. Pass-by-Value vs Pass-by-Reference

In C, function arguments are passed by value by default, meaning a copy of the variable is created, and any modifications affect only that local copy. Pointers allow pass-by-reference behavior so functions can work directly with the original memory location.

Pass-by-Value Pass-by-Reference
Copy of data is passed Address is passed
Original value unchanged Original value can be modified
More memory for large data More efficient
Safer for read-only operations Useful when modifications are required

Example: Pass-by-Reference

#include <stdio.h>

void increment(int *num)
{
    (*num)++;
}

int main()
{
    int x = 10;
    increment(&x);
    printf("%d\n", x); // Outputs 11

    return 0;
}

3. Returning Pointers from Functions

Functions can return pointers, but doing so safely requires careful attention to memory scope (Stack vs. Heap).

Returning Dynamically Allocated Memory (Safe)

A safe way to return pointers is by returning memory allocated on the heap via malloc(), which persists until explicitly freed.

#include <stdio.h>
#include <stdlib.h>

int* createNumber()
{
    int *ptr = (int *)malloc(sizeof(int));
    *ptr = 100;
    return ptr;
}

int main()
{
    int *num = createNumber();
    printf("%d\n", *num);
    free(num);

    return 0;
}

Returning the Address of a Local Variable (Danger)

Returning local stack variables (e.g., int* getValue() { int x = 50; return &x; }) results in a dangling pointer because the stack memory is destroyed once the function finishes executing.

4. Advanced Pointer Parameters & Multiple Values

Because arrays decay into pointers, functions easily accept array arguments. Furthermore, pointers allow functions to return multiple values through output parameters.

Example: Returning Multiple Values (Min and Max)

#include <stdio.h>

void minMax(int a, int b, int *min, int *max)
{
    if(a < b)
    {
        *min = a;
        *max = b;
    }
    else
    {
        *min = b;
        *max = a;
    }
}

int main()
{
    int minimum, maximum;
    minMax(15, 8, &minimum, &maximum);

    printf("Min = %d\n", minimum);
    printf("Max = %d\n", maximum);

    return 0;
}

5. Const Pointers vs Pointers to Const

Qualifiers like const help enforce safety constraints on pointers:

  • Pointer to Const (const int *ptr): The data pointed to cannot be modified, but the pointer can point elsewhere.
  • Const Pointer (int *const ptr): The pointer itself cannot change its destination, but the underlying data can be modified.
Declaration Meaning
const int *ptr Data is constant (value cannot change through pointer)
int *const ptr Pointer is constant (address cannot change)
const int *const ptr Both data and pointer are constant

6. Introduction to Function Pointers

Functions reside at specific locations in memory. A function pointer can store that address, enabling callbacks, event handling, and dynamic dispatch.

#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int (*func)(int, int) = add;
    printf("%d\n", func(5, 3)); // Outputs 8

    return 0;
}

7. Mini Project: Reverse a String Using Pointers

Write a function that reverses a string in place using pointers.

#include <stdio.h>
#include <string.h>

void reverse(char *str)
{
    char *start = str;
    char *end = str + strlen(str) - 1;

    while(start < end)
    {
        char temp = *start;
        *start = *end;
        *end = temp;

        start++;
        end--;
    }
}

int main()
{
    char text[] = "Hello";
    reverse(text);
    printf("%s\n", text); // Outputs: olleH

    return 0;
}
