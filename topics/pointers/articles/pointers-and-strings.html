1. Introduction

Strings are one of the most frequently used data types in C programming. Unlike many modern programming languages that provide a built-in String data type, C represents strings as arrays of characters terminated by a null character (\0). Since array names behave like pointers, strings and pointers are naturally connected.

Using pointers to manipulate strings is more efficient than using array indexing in many situations. Most standard library string functions such as strlen(), strcpy(), strcmp(), and strcat() internally use pointer arithmetic. Understanding string manipulation through pointers is therefore an essential skill for every C programmer.

2. Strings, Memory Representation & Character Arrays

A string is a sequence of characters terminated by a null character (\0). The array name represents the address of its first character (i.e., str == &str[0]), allowing us to assign it directly to a character pointer like char *ptr = str;.

Character Arrays vs. String Literals

Character Array (`char str[] = "Hello";`) String Literal (`char *str = "Hello";`)
Stored in writable memory (Stack) Stored in read-only memory
Can be modified freely Should not be modified (causes undefined behavior)
Owns the underlying character data Points to a read-only constant data location

3. Traversing and Modifying Strings Using Pointers

Instead of relying on array indices, pointers can traverse character arrays until encountering the null terminator.

#include <stdio.h>

int main()
{
    char str[] = "Hello";
    char *ptr = str;

    while(*ptr != '\0')
    {
        printf("%c ", *ptr);
        ptr++;
    }

    return 0;
}

Modifying Mutable Strings

Because character arrays are writable, modifying elements via pointers is straightforward:

char str[] = "Hello";
char *ptr = str;
*ptr = 'Y'; // Changes "Hello" to "Yello"

4. Implementing Standard String Functions Using Pointers

Standard operations can be implemented efficiently via pointer arithmetic:

String Length (`strlen`)

int stringLength(char *str)
{
    int count = 0;
    while(*str != '\0')
    {
        count++;
        str++;
    }
    return count;
}

String Copy (`strcpy`)

void stringCopy(char *dest, char *src)
{
    while(*src != '\0')
    {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0';
}

5. Arrays of Strings & Double Pointers

Multiple strings are typically represented as an array of character pointers (`char *colors[]`), which act as a char ** double pointer structure.

#include <stdio.h>

int main()
{
    char *colors[] = { "Red", "Green", "Blue", "Yellow" };
    char **ptr = colors;

    for(int i = 0; i < 4; i++)
    {
        printf("%s\n", ptr[i]);
    }

    return 0;
}

6. Common Beginner Mistakes

  • Forgetting the Null Character: Declaring fixed-size character arrays without accounting for the mandatory \0 terminator.
  • Modifying String Literals: Attempting to change contents of pointer-assigned string literals (e.g., char *str = "Hello"; str[0] = 'Y';), causing segmentation faults.
  • Buffer Overflows: Copying strings into destination arrays that are too small to hold them.
  • Unbounded Loops: Traversing pointers past the null character without a proper termination check.

7. Mini Project: Word Counter Using Pointer Traversal

Write a C program that counts the number of words in a sentence using pointer traversal only.

#include <stdio.h>

int countWords(char *str)
{
    int words = 0;
    int inWord = 0;

    while(*str)
    {
        if(*str != ' ' && *str != '\t' && *str != '\n')
        {
            if(!inWord)
            {
                words++;
                inWord = 1;
            }
        }
        else
        {
            inWord = 0;
        }
        str++;
    }

    return words;
}

int main()
{
    char text[100];
    printf("Enter a sentence: ");
    fgets(text, sizeof(text), stdin);

    printf("Number of words = %d\n", countWords(text));
    return 0;
}
