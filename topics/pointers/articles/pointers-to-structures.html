1. Introduction

Structures are one of the most powerful features of the C programming language, allowing multiple related variables of different data types to be grouped into a single user-defined data type. When combined with pointers, structures become even more powerful, enabling efficient memory management, dynamic object creation, and the implementation of complex data structures such as linked lists, trees, graphs, stacks, and queues.

Pointers to structures eliminate the need to copy large structures, improve program performance, and provide dynamic memory allocation capabilities. They are extensively used in operating systems, databases, networking software, game engines, and embedded systems.

2. Declaring and Accessing Structure Pointers

A structure pointer stores the memory address of an instantiated structure variable. Members can be accessed either via explicit dereferencing (*ptr).member or using the preferred shorthand arrow operator ptr->member.

#include <stdio.h>
#include <string.h>

struct Student {
    int roll;
    char name[30];
    float marks;
};

int main() {
    struct Student student;
    struct Student *ptr = &student;

    ptr->roll = 101;
    strcpy(ptr->name, "Alice");
    ptr->marks = 95.5;

    printf("Roll : %d\nName : %s\nMarks : %.2f\n", ptr->roll, ptr->name, ptr->marks);
    return 0;
}

Dot Operator vs Arrow Operator

Dot Operator (.) Arrow Operator (->)
Used with direct structure variables (e.g., student.roll) Used with structure pointers (e.g., ptr->roll)
Direct member lookup Implicit dereference and member lookup combined

3. Passing Structures to Functions

Passing large structures by value incurs performance penalties due to data copying. Passing structure pointers avoids copying entirely and allows functions to mutate original data.

void display(struct Student *s) {
    printf("Roll: %d, Name: %s\n", s->roll, s->name);
}

// Called as: display(&student);

4. Dynamic Structure Allocation & Self-Referential Structures

Structures can be allocated on the heap using malloc(), which is vital for building collections or data structures whose sizes vary at runtime.

Self-Referential Structures

A structure containing a pointer to an instance of itself forms the foundation for dynamic data structures like linked lists, trees, and graphs:

struct Node {
    int data;
    struct Node *next; // Pointer to another node of the same type
};

5. Common Beginner Mistakes

  • Operator Precedence Issues: Writing *ptr.roll instead of correctly parenthesizing it as (*ptr).roll or using ptr->roll.
  • Uninitialized Pointers: Accessing members of a structure pointer (e.g., ptr->roll = 10;) without allocating memory first.
  • Memory Leaks: Forgetting to call free() on dynamically allocated structure objects.
  • Confusing Operators: Using the dot operator (.) instead of the arrow operator (->) with pointers.

6. Mini Project: Student Record Management System

A program that dynamically allocates memory for multiple student records, accepts input, displays info, and cleans up memory.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

struct Student {
    int roll;
    char name[50];
    float marks;
};

int main()
{
    int n;
    printf("Enter number of students: ");
    scanf("%d", &n);

    struct Student *students = (struct Student *)malloc(n * sizeof(struct Student));
    if(students == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    for(int i = 0; i < n; i++) {
        printf("\nStudent %d\n", i + 1);
        printf("Roll: ");
        scanf("%d", &students[i].roll);
        printf("Name: ");
        scanf("%s", students[i].name);
        printf("Marks: ");
        scanf("%f", &students[i].marks);
    }

    printf("\nStudent Records\n");
    for(int i = 0; i < n; i++) {
        printf("Roll: %d\nName: %s\nMarks: %.2f\n\n", students[i].roll, students[i].name, students[i].marks);
    }

    free(students);
    return 0;
}
